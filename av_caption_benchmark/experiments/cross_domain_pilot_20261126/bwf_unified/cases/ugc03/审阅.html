视觉动作 · 联合复核后

  • A01　S01-P01　motion / 切肉　0.000–0.584 秒
    动作简述　P01 用刀把砧板上的肉块切开一次。
    详细描述　右手握着带花纹的大厨刀悬在一块深褐色肉上方，刀刃向下切入木质砧板上的肉块。随着下压推进，刀身逐渐贴近砧板，最后停在已分开成两段的肉之间。
    画面证据　0.542209 秒　刀已落到砧板上，肉被分成两段
    子阶段　0.000–0.209 秒　举刀对准肉块　右手持刀位于肉块上方，准备下切。
    子阶段　0.209–0.584 秒　下压切断　刀刃持续压入肉块并接近砧板，最终完成一次切割。
    关键点　0.208542　刀刃接触肉面
    关键点　0.542209　刀抵近砧板
  • A02　S02-P01　motion / 切肉　0.584–1.126 秒
    动作简述　P01 在同一镜头内再次下刀切开肉块。
    详细描述　画面重新回到同一块肉的近景，右手再次握刀从上方向下压切。左手扶住肉块边缘，刀身一路下沉直到贴近砧板，形成又一次分离切口。
    画面证据　1.08442 秒　刀已深入肉块接近底部
    子阶段　0.584–0.792 秒　抬刀定位　右手把刀重新提起并对准肉块表面。
    子阶段　0.792–1.126 秒　压下切开　刀沿竖直方向继续下压，直至接近砧板。
    关键点　0.792459　二次落刀
    关键点　1.084418　切至砧板附近
  • A03　S03-P01　motion / 切肉　1.126–1.585 秒
    动作简述　P01 连续完成第三段切肉动作。
    详细描述　第三次出现相似的切肉近景，右手握刀压在肉块上并向下滑动到底。左手仍按在肉旁保持稳定，结束时刀面贴着砧板和分开的肉段。
    画面证据　1.54321 秒　刀滑到砧板处，肉段分开更明显
    子阶段　1.126–1.418 秒　压入肉块　刀从上方压进肉里，逐步接近砧板。
    子阶段　1.418–1.585 秒　滑动收尾　刀继续沿砧板方向滑到底部并停下。
    关键点　1.334668　持续下压
    关键点　1.54321　触底停住
  • A04　S04-P01　motion / 舀取酱汁　1.585–2.169 秒
    动作简述　P01 从玻璃罐中舀起一勺橙色酱汁并移到面包上方。
    详细描述　左手扶着装有橙色浓稠酱汁的玻璃罐，右手持金属勺探入罐口。随后勺子向上提起，带出一团挂在勺面上的酱汁，移到前景的一片烤面包上方。
    画面证据　2.08542 秒　盛满酱汁的勺子离开罐口并悬在面包上方
    子阶段　1.585–1.877 秒　在罐内舀酱　右手把勺子插入橙色酱汁中收集一团。
    子阶段　1.877–2.169 秒　提勺转移　勺子带着酱汁上升并平移到面包上方。
    关键点　1.876877　勺离罐口
    关键点　2.085419　移至面包上方
  • A05　S05-P01　motion / 涂抹酱汁　2.169–2.711 秒
    动作简述　P01 用勺背把橙色酱汁均匀涂在一片烤面包上。
    详细描述　右手控制勺背贴在面包表面来回抹开橙色酱汁，左手轻按面包边防止移动。原本集中的酱团被摊平成一层较均匀的涂层，铺满面包中部。
    画面证据　2.66934 秒　面包表面已被大面积涂匀
    子阶段　2.169–2.461 秒　推展酱团　勺背把中央的酱团向外推开。
    子阶段　2.461–2.711 秒　抹平收整　继续在面包表面往返刮抹，使涂层变薄变均匀。
    关键点　2.252252　开始铺开
    关键点　2.669336　基本涂满
  • A06　S06-P01　motion / 放置肉块　2.711–3.253 秒
    动作简述　P01 把一块熟肉放到涂好酱汁的面包上。
    详细描述　双手托着一块深色熟肉从画面上方进入，缓慢下降到已经涂好橙色酱汁的面包上。肉块落下后贴合面包表面，位置居中略靠前。
    画面证据　3.21155 秒　肉块已稳稳放在涂酱面包上
    子阶段　2.711–3.003 秒　悬空搬运　双手把肉块移到面包上方并保持水平。
    子阶段　3.003–3.253 秒　放下贴合　肉块缓缓下落并与涂酱面包接触。
    关键点　3.003003　下降接近面包
    关键点　3.211545　接触落定
  • A07　S07-P01　motion / 按压肉块　3.253–3.629 秒
    动作简述　P01 用手掌把三明治上的肉块往下按压固定。
    详细描述　一只手张开覆在肉块顶部向下施力，另一只手在侧后方辅助稳定。受压后肉块略微塌陷并更紧地贴在面包上，手指保持短促按压姿态。
    画面证据　3.58692 秒　肉块被压实，厚度看起来更低
    子阶段　3.253–3.462 秒　搭上肉块　手掌先覆盖到肉块表面建立接触。
    子阶段　3.462–3.629 秒　向下压实　保持掌压使肉块与面包贴合更紧。
    关键点　3.33667　掌心接触
    关键点　3.58692　持续下压
  • A08　S08-P01　motion / 加黄瓜丝　3.629–3.962 秒
    动作简述　P01 用筷子把浅色丝状配菜夹到肉块上。
    详细描述　一双木筷从左侧容器区域夹起浅绿白色的细条状配菜，移动到肉块上方后松开。菜丝散落在深色肉面上，形成第一层蔬菜配料。
    画面证据　3.92059 秒　丝状配菜已落在肉块表面
    子阶段　3.629–3.837 秒　从旁边夹料　筷子伸向旁边的容器并夹起浅色丝状配菜。
    子阶段　3.837–3.962 秒　放到肉上　筷子移到肉块上方后放开，让菜丝散落其上。
    关键点　3.712045　夹起配菜
    关键点　3.920587　松筷投放
  • A09　S09-P01　motion / 加黄瓜片　3.962–4.421 秒
    动作简述　P01 继续用筷子往三明治上加更大的圆黄瓜片。
    详细描述　筷子再次从左侧取来较大的圆形绿色瓜片，逐片叠放在已有菜丝的三明治顶部。新增的瓜片比先前更宽更厚，覆盖住部分下层配料。
    画面证据　4.37938 秒　多片圆黄瓜片堆叠在顶部
    子阶段　3.962–4.254 秒　续夹瓜片　筷子反复从旁边夹取圆形绿色瓜片。
    子阶段　4.254–4.421 秒　铺顶覆盖　瓜片被一片片放到最上层，遮住下方丝状配菜。
    关键点　4.170838　夹起大片
    关键点　4.379379　叠放完成
  • A10　S10-P01　motion / 淋调味液　4.421–5.130 秒
    动作简述　有人从上方给做好的半成品三明治淋上一层透明液体。
    详细描述　一股透明发亮的液体从画面上方倒下，浇在黄瓜片和肉块交界处。液体顺着重力流过蔬菜表面并渗入缝隙，最后在砧板上留下零星湿痕。
    画面证据　5.08842 秒　蔬菜表面湿润反光，周围有滴落痕迹
    子阶段　4.421–4.713 秒　初始浇注　透明液体首先打在黄瓜片上。
    子阶段　4.713–5.130 秒　顺流浸润　液体沿着蔬菜和肉面往下流动并扩散。
    关键点　4.504505　液体触及顶部
    关键点　5.005005　流淌扩散
  • A11　S11-P01　motion / 挤橙色酱汁　5.130–5.672 秒
    动作简述　P01 用红嘴瓶把橙色酱汁挤在黄瓜和肉块上。
    详细描述　一只带红色尖嘴的瓶子出现在画面上方，朝三明治挤出粗条状的橙色酱汁。酱汁以斜向线条覆盖在黄瓜片和肉块上，停留时间较短但分布明显。
    画面证据　5.63063 秒　多条橙色酱线留在蔬菜表面
    子阶段　5.130–5.339 秒　对位准备　红色瓶嘴移到三明治上方并对准中心区域。
    子阶段　5.339–5.672 秒　划线式挤出　橙色酱汁成束流出，在表面拖出数道斜线。
    关键点　5.213547　瓶嘴对准三明治
    关键点　5.547214　挤出条纹
  • A12　S12-P01　motion / 撒香草碎　5.672–6.381 秒
    动作简述　P01 往三明治上撒了一层绿色香草碎。
    详细描述　细小的深绿色碎片从上方飘落，散布到已经挤过橙色酱汁的三明治表面。手指只在画面边缘短暂出现，主要可见的是碎叶不断落下并附着在湿润配料上。
    画面证据　6.33967 秒　三明治表面布满零散绿叶碎
    子阶段　5.672–5.964 秒　抛洒起步　第一批绿色碎叶从上方落下。
    子阶段　5.964–6.381 秒　补撒扩展　更多碎叶连续落下，覆盖面扩大到整个顶部。
    关键点　5.755756　首次洒落
    关键点　6.256256　持续覆盖
  • A13　S13-P01　motion / 合上面包　6.381–7.883 秒
    动作简述　P01 把另一片面包盖上去并用力压合成完整三明治。
    详细描述　双手捏住另一片长条面包的两端，把它从上方扣到已装满配料的底层面包上。合拢后十指顺势向下压顶，使上下两层夹紧，夹层里的酱汁和蔬菜被轻微挤出边缘。
    画面证据　7.84117 秒　双手仍按在封好的三明治顶部
    子阶段　6.381–6.798 秒　搬运封顶　双手把第二片面包移到上方并落下盖住馅料。
    子阶段　6.798–7.883 秒　压紧定型　手指和手掌持续向下按压，令三明治闭合更紧。
    关键点　6.67334　顶层接触
    关键点　7.590924　整体下压
  • A14　S14-P01　motion / 切开三明治　7.883–8.509 秒

    子阶段　7.883–8.091 秒　定位起手　左手压住面包，右手把刀立在中线位置。
    子阶段　8.091–8.509 秒　向下剖开　刀具连续穿过各层馅料，把整体切成两份。
    关键点　7.9663　破壳下刀
    关键点　8.383383　贯穿内馅
  • A15　S15-P01　held_pose / 展示截面　8.509–9.593 秒

    子阶段　8.509–9.593 秒　举起定格　双手持续把截面保持在镜头前方供观看。

  • A16　S17-P01　motion / 拧开罐盖　10.302–10.719 秒

  • A18　S19-P01　motion / 舀起蛋黄酱　11.136–11.720 秒

    关键点　11.678345　高位停顿
