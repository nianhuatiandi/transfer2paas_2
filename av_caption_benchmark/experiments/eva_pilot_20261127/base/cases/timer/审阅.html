视觉动作 · 联合复核后

  • S01-A01　S01-P01　motion / 按下调时间按钮　0.000–1.290 秒
    动作简述　右手食指在控制器左列箭头键上连续按压，把时间调到7:00。
    详细描述　画面开始时，右手食指已贴在控制器左列上方箭头键上；随后手指持续在该按键区域反复下压，液晶显示先见“7:15”，之后变为“7:00”。到本段末尾，食指离开左列按键并向右移动，准备去按另一组按钮。
    画面证据　0 秒　右手食指放在左侧向上箭头键上，屏幕显示约7:15
    画面证据　0.58 秒　食指仍在左列按键处，屏幕已变为7:00
    画面证据　1.21 秒　食指开始从左列移开，朝右侧按钮区滑动
    子阶段　0.000–1.210 秒　按住并按压左列箭头键　食指停留在左列上下箭头附近，连续做短促按压动作，期间屏幕数值发生变化。
    子阶段　1.210–1.290 秒　向右换键　食指抬起后横移到右侧按钮区，完成目标切换。
    关键点　0.58　屏幕时间改变
    关键点　1.29　手指离开左列
  • S01-A02　S01-P01　motion / 按下调天数按钮　1.290–2.380 秒
    动作简述　右手食指改按控制器右列箭头键，使天数从7增加到8。
    详细描述　食指移到右侧一列上下箭头键后继续点按，屏幕右侧数字先为7，后面变成8。镜头切走前，手指仍停在右列按键附近，没有看到完整收手过程。
    画面证据　1.42 秒　食指落在右侧向上箭头键上
    画面证据　2 秒　屏幕右侧数字变为8，手指仍在右列按键区
    画面证据　2.38 秒　临近切镜时手指尚未明显撤离
    子阶段　1.290–2.380 秒　按压右列箭头键　食指在右侧上下箭头键上做连续短按，屏幕对应数值随之更新。
    关键点　1.29　切换到右列按键
    关键点　2.0　天数增加
  • S02-A01　S02-P01　motion / 插上电源适配器　2.420–3.340 秒
    动作简述　双手把黑色电源适配器推入墙面插座。
    详细描述　两只手共同握持一个黑色长方体适配器，对准墙盒下方插座的孔位向前推送；随着两手同步用力，适配器逐渐没入插座，最后基本贴合面板。
    画面证据　2.42 秒　双手握着适配器靠近墙面插座
    画面证据　3 秒　适配器大部分已进入插座，只剩外侧部分外露
    画面证据　3.34 秒　适配器几乎完全插入，手部仍扶在其外缘
    子阶段　2.420–2.710 秒　握持并对准插口　两手夹住适配器两侧，把它抬到插座前方并对齐孔位。
    子阶段　2.710–3.340 秒　推进插座　双手持续向前施力，适配器逐步深入，直到与面板接近齐平。
    关键点　2.42　对准插座
    关键点　3.34　插入到位
  • S02-A02　S02-P01　motion / 拔下电源适配器　3.340–3.920 秒
    动作简述　双手把刚插入的黑色适配器从墙面插座中拔出。
    详细描述　接着上一动作，双手重新抓住适配器外缘向后拉；适配器的金属插脚先从插座中退出，整个机身被抽离墙面，最后移出画面左下区域，只留下空插座。
    画面证据　3.42 秒　双手仍握住适配器，开始向外撤
    画面证据　3.71 秒　适配器已经离开插座一段距离
    画面证据　3.92 秒　适配器几乎完全出画，墙面插座空置
    子阶段　3.340–3.500 秒　抓稳适配器　两手从扶握转为更明确地夹住适配器边缘，准备反向用力。
    子阶段　3.500–3.920 秒　向外抽出　适配器整体后退，插脚脱出插座，随后连同人手一起移出画面。
    关键点　3.34　开始回拔
    关键点　3.92　完全脱离插座
  • S03-A01　S03-P01　motion / 撕下胶带标签　4.090–7.170 秒
    动作简述　双手把写有标记的米色胶带从线缆上慢慢撕下来。
    详细描述　两只手的拇指和食指捏住一小块米色胶带标签的两端，标签上有手写数字痕迹；随后两手朝相反方向缓慢拉开，胶带从一束线缆表面一点点揭起，越往后卷曲越明显，最终形成半脱落状态。
    画面证据　4.09 秒　双手捏住带手写标记的小块胶带，贴在黑色线缆束上
    画面证据　5.51 秒　胶带已被掀起一部分，仍连着线缆
    画面证据　7.09 秒　胶带大幅翘起，接近整条剥落
    子阶段　4.090–4.500 秒　夹住胶带边缘　左右手分别用拇指和食指固定胶带两侧，建立稳定的受力点。
    子阶段　4.500–7.170 秒　慢慢揭开胶带　两手持续向相反方向轻拉，胶带自一端起翘，再沿长度方向逐步脱离线缆表面。
    关键点　4.09　捏住标签两端
    关键点　7.09　胶带明显翘起
  • S03-A02　S03-P01　motion / 分理彩色导线　7.170–9.470 秒
    动作简述　双手把缠在一起的红、绿、蓝等多根细导线逐一分开整理。
    详细描述　胶带掀开后，双手转到线缆末端，把原本聚在一起的几根红、绿、蓝等颜色的细导线逐根拨开；手指在线束间穿插、捻动和下拉，使各线彼此分离，末端裸出的小线头越来越清楚。
    画面证据　7.29 秒　胶带已翻开，双手开始碰触线束末端的多根彩线
    画面证据　8 秒　数根不同颜色导线已被分开成扇形
    画面证据　9.38 秒　多根细线彼此独立垂下，线头清晰可见
    子阶段　7.170–8.000 秒　触碰并挑出线芯　手指探入线束外层，先把最外侧的一两根彩线单独拎出来。
    子阶段　8.000–9.470 秒　逐根展开剩余导线　两手交替把其余彩线一根根拨离主线束，使它们呈放射状下垂。
    关键点　7.17　开始拨线
    关键点　9.38　线束散开
  • S04-A01　S04-P01　motion / 拧紧紧固螺丝　9.510–11.140 秒
    动作简述　操作者用螺丝刀拧紧控制器端子排上的螺丝。
    详细描述　左手扶住螺丝刀的深色杆部和前端，把刀头抵在控制器底部端子排的螺丝上；右手握住透明手柄做旋转动作，手腕来回带动手柄转动，螺丝随旋紧而嵌入端子位置。切镜前螺丝刀仍顶在端子上。
    画面证据　9.51 秒　螺丝刀已伸到端子排处，左手扶杆，右手握手柄
    画面证据　10.01 秒　右手手柄处于转动姿态，左手保持稳定支撑
    画面证据　11.09 秒　螺丝刀仍压在端子上，动作尚未结束
    子阶段　9.510–9.800 秒　定位螺丝刀　左手把螺丝刀送到端子排螺丝上方并对正槽口，右手接住手柄准备发力。
    子阶段　9.800–11.140 秒　旋转拧紧　右手以腕部为主转动手柄，左手始终扶住杆身防止滑脱，螺丝被逐步压紧。
    关键点　9.51　刀头抵住螺丝
    关键点　10.01　持续旋转手柄
  • S05-A01　S05-P01　motion / 合上控制器外壳　11.180–11.640 秒
    动作简述　双手把黄色控制器外壳扣回底座并压实。
    详细描述　双手分别托住黄色控制器外壳的左右边，把它从前方罩到已装好的底座上；随着两手向内、向后压，壳体边缘逐渐贴齐底座，底部蓝色端子排被遮住一部分，最后外壳基本就位但仍能看到双手扶着边框。
    画面证据　11.18 秒　双手拿着黄色外壳对准底座，壳下还能看见端子排
    画面证据　11.47 秒　外壳已覆盖大部分正面，边缘接近贴合
    画面证据　11.64 秒　外壳基本装上，双手仍扶在两侧
    子阶段　11.180–11.390 秒　举起并对准底座　双手把外壳抬到控制器前面，让四边与底座轮廓对齐。
    子阶段　11.390–11.640 秒　压下并贴合　两手同时向内收拢并下压，外壳逐步扣满底座，露出的端子区域减少。
    关键点　11.18　外壳对位
    关键点　11.64　压合到位
