人物与执行段

  • SE01　0.000–0.600 秒　黑衣男子双手将球向上托起传给黄衣男子
  • SE02　1.500–2.400 秒　黄衣男子起跳并单手将排球扣过网

视觉动作 · 无声帧初标

  • A01　S01-P01　motion / 托球　0.000–0.600 秒
    动作简述　黑衣男子双手将球向上托起传出。
    详细描述　黑衣男子双手举过头顶接触排球，随后手臂向上伸展发力，将球向斜上方托出，直至双手离开排球。
    画面证据　0 秒　黑衣男子双手持球于头顶上方准备动作。
    画面证据　0.3 秒　黑衣男子手臂完全伸直，排球刚脱离双手。
    画面证据　0.6 秒　排球已飞向空中，黑衣男子保持手臂上伸姿势。
    关键点　0.3　脱手瞬间
  • A03　S01-P02　gesture / 举手示意接球　0.000–1.500 秒
    动作简述　黄衣男子在空中举起双手，准备迎接传来的排球。
    详细描述　黄衣男子双脚离地悬空，双臂高举过头顶，手掌张开朝向传过来的排球，做出准备触球的姿态。
    画面证据　0 秒　黄衣男子处于跳跃状态，双手举起准备接球。
    画面证据　1 秒　黄衣男子在空中调整位置，双手依然保持高举姿势等待排球到达最高点。
  • A02　S01-P01　held_pose / 站立观察　0.600–3.000 秒
    动作简述　黑衣男子站立不动，观察对方的扣球动作。
    详细描述　黑衣男子双脚着地站立，头部跟随飞行的排球移动，视线始终注视着对面的黄衣男子及其动作。
    画面证据　1 秒　黑衣男子站在原地，抬头看着空中的排球。
    画面证据　2 秒　黑衣男子保持站立姿势，目光跟随着正在扣球的黄衣男子。
  • A04　S01-P02　motion / 扣球　1.500–2.400 秒
    动作简述　黄衣男子跃起并用右手大力将排球扣向对方场地。
    详细描述　黄衣男子在空中达到最高点后，右臂向后弯曲蓄力，随后向前挥动，用手掌击打排球顶部将其向下扣过球网，左臂自然下垂或微张以保持平衡。
    画面证据　1.8 秒　黄衣男子右臂高高扬起，身体呈反弓形准备发力。
    画面证据　2.1 秒　黄衣男子右手即将接触到排球。
    画面证据　2.4 秒　排球被击中并开始向下飞行，黄衣男子手臂随惯性下摆。
    子阶段　1.500–2.000 秒　引臂蓄力　黄衣男子在空中将右臂向后上方抬起，肘部弯曲，手掌打开准备击球。
    子阶段　2.000–2.400 秒　挥臂击球　黄衣男子快速向前下方挥动右臂，全掌拍击排球上部。
    关键点　2.2　击球瞬间
  • A05　S01-P02　motion / 落地缓冲　2.400–3.000 秒
    动作简述　黄衣男子扣球结束后从空中落下并站稳。
    详细描述　完成扣球后，黄衣男子身体下落，双脚先后接触地面，膝盖弯曲以吸收冲击力，最终恢复站立姿态。
    画面证据　2.7 秒　黄衣男子脚部接近地面。
    画面证据　2.9 秒　黄衣男子双脚稳稳站在地面上，身体略微前倾。
    关键点　2.8　触地瞬间
