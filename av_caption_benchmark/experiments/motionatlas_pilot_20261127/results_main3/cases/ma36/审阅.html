视觉动作 · 联合复核后

  • A-S01-P01-ClimbLadder　S01-P01　motion / 攀爬梯子　0.000–1.301 秒
    动作简述　主角戴着手套的双手交替抓握梯级，推动视角向上移动完成攀爬。
    详细描述　初始状态下，主角右手紧握梯子右侧竖直栏杆（0.0s）。随后左手抓住下方横档（0.2s），右手迅速上移至更高处的横档（0.5s）。这种手脚交替向上的模式持续进行，视野随之不断升高，周围的砖墙纹理逐渐后退。约在1.1s时，双手最后一次用力上拉，视野越过梯子顶部的横梁结构。至1.3s，手部完全脱离梯子框架出画，标志着攀爬动作结束，主角已抵达屋顶平面。
    画面证据　0 秒　右手特写，紧抓梯子右侧绿色发光的竖杆。
    画面证据　0.2 秒　左手出现在左下方，握住一根横向梯级。
    画面证据　0.5 秒　右手再次出现，位置比之前更高，抓住了新的横档。
    画面证据　1.1 秒　视野接近梯子顶端开口处，可以看到上方的平台边缘。
    画面证据　1.3 秒　手部消失，视野变为开阔的屋顶瓦片，确认登顶成功。
    子阶段　0.000–0.300 秒　起步抓握　确立初始支点，右手高抓竖杆，左手低抓横档。
    子阶段　0.300–1.000 秒　交替上行　典型的爬梯节奏，一手固定一手移动，视野稳步抬升。
    子阶段　1.000–1.301 秒　登顶脱手　最后一步拉升，身体重心转移至屋顶，双手退出视野。
  • A-S01-P01-RaiseWeapon　S01-P01　motion / 举枪警戒　1.752–2.486 秒
    动作简述　主角将配备消音器的步枪从低位抬起，进入据枪瞄准状态。
    详细描述　在短暂的空窗期（约1.4s-1.7s）适应屋顶环境后，1.75s时枪管前端切入画面中央偏下位置。紧接着，整个枪身被平稳地托起，露出顶部的导轨和红点瞄准镜。左手护木握持位置清晰可见，右手扳机手指搭在护圈外（非射击态）。最终在2.0s后保持静止的警戒姿态，枪口微微上扬指向远处的铁丝网围栏方向，直至片段结束。
    画面证据　1.75175 秒　白色的消音器枪头首先出现在画面正中下方。
    画面证据　1.9 秒　枪身上部结构显现，包括提把位置的瞄具底座。
    画面证据　2 秒　完整的步枪形态呈现，处于标准的腰际/胸际持枪高度。
    画面证据　2.4 秒　姿势未变，持续监视前方屋顶边缘的障碍物。
    子阶段　1.752–2.002 秒　出枪　武器从不可见状态迅速提升至视野中心。
    子阶段　2.002–2.486 秒　据枪锁定　维持稳定的持枪角度，微调指向以覆盖潜在威胁区。
