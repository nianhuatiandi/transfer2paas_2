视觉动作 · 无声帧初标

  • ACT-S01-P01-WALK　S01-P01　motion / 拄拐行走　0.000–1.500 秒
    动作简述　左侧剪影人物拄着拐杖缓慢走了几步后停下。
    详细描述　人物呈剪影状态，左手持一根细长的拐杖支撑在地面上。从0.0秒开始，右腿向前迈出，随后左腿跟上，身体重心随步伐前移。约1.0秒时停止迈步，双腿前后分开站立，拐杖继续支撑地面直至镜头结束。
    画面证据　0 秒　人物侧身站立，左手持拐杖触地
    画面证据　0.375 秒　右腿明显向前跨出一步
    画面证据　0.625 秒　左腿跟进，双脚位置改变
    画面证据　1 秒　停止走动，保持双腿分开的静止姿态
    画面证据　1.5 秒　维持站立姿势直到切镜
    子阶段　0.000–1.000 秒　迈步前行　交替迈动双腿，利用拐杖辅助平衡，向画面左侧缓慢移动。
    子阶段　1.000–1.500 秒　驻足停留　双脚站定不再移动，仅保持拄拐的静态姿势。
    关键点　0.375　起步
    关键点　1.0　停步
  • ACT-S01-P02-STAND　S01-P02　held_pose / 静立旁观　0.000–1.500 秒
    动作简述　右侧剪影人物全程静立看着对方。
    详细描述　人物位于画面右侧，面向左侧的另一人站立。在整个镜头期间，除了极细微的身体晃动外，没有明显的位移或肢体动作，始终保持双手似乎插在口袋里的放松站姿。
    画面证据　0 秒　人物直立面对左侧同伴
    画面证据　0.75 秒　姿态未发生改变
    画面证据　1.5 秒　依然保持原位站立
  • ACT-S02-P01-STAND　S02-P01　held_pose / 背影伫立　1.625–6.500 秒
    动作简述　近景中的人物背对镜头静静伫立在海边。
    详细描述　镜头切换为近景，人物以黑色剪影形式占据画面左侧大部分区域，背对镜头面向大海。头发略显凌乱，随风轻微飘动。除头部有极其微小的转动调整外，躯干和四肢基本保持静止不动的状态。
    画面证据　1.625 秒　切入近景，人物背部朝向观众
    画面证据　3 秒　发丝因风吹起而抖动
    画面证据　6.5 秒　直至片段结束仍保持该背影姿态
  • ACT-S02-O01-MOVE　S02-O01　motion / 鹅头探出与缩回　3.875–6.500 秒
    动作简述　一只鹅的头颈从人物左肩后探出并在其耳边活动。
    详细描述　起初（1.625s-3.75s）只能看到人物肩膀上方有一个尖状突起。从3.875秒开始，一个清晰的长颈鸟类（疑似鹅）的头部和颈部轮廓从人物左肩后方伸出，喙部指向左侧。随后这只鸟的头部在肩头附近小幅度上下起伏、左右摆动，偶尔贴近人物耳侧，最后又稍微向后收缩但仍露出部分脖颈。
    画面证据　3.875 秒　鹅的完整头颈轮廓首次清晰显现于左肩处
    画面证据　4.25 秒　鹅嘴微张或闭合的动作导致轮廓变化
    画面证据　4.75 秒　鹅头向上抬起靠近人物脸颊
    画面证据　5.5 秒　鹅头再次向下低垂
    画面证据　6.5 秒　鹅头略微后撤但仍在视野内
    子阶段　3.875–4.500 秒　探头展示　长长的脖颈完全伸直，将头部清晰地暴露在逆光背景中。
    子阶段　4.500–6.500 秒　局部活动　头部围绕肩部进行小幅度的点头、转头动作。
    关键点　3.875　显露全貌
    关键点　4.75　抬头亲昵
